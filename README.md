# Fitur Utama Aplikasi
1. Katalog Produk
Menyediakan halaman yang menampilkan berbagai produk dalam bentuk kartu sehingga pengguna dapat melihat produk yang tersedia.

2. Tambah Produk
Memungkinkan pengguna memasukkan produk baru beserta informasi yang diperlukan ke dalam katalog.

3. Ubah Data Produk
Memberikan fasilitas untuk memperbarui informasi produk yang telah ada, termasuk nama dan harga produk.

4. Hapus Produk
Memungkinkan pengguna menghilangkan produk dari katalog melalui proses konfirmasi untuk mencegah penghapusan yang tidak disengaja.

5. Pemeriksaan Input
Menerapkan validasi pada setiap data yang dimasukkan agar sesuai dengan format dan aturan yang telah ditentukan.

6. Database Produk
Memanfaatkan SQLite sebagai media penyimpanan sehingga informasi produk dapat disimpan dan dikelola.
Dokumentasi Tampilan
Bagian ini memperlihatkan hasil implementasi aplikasi Katalog Produk UPI Store, mulai dari halaman utama hingga tampilan daftar produk yang tersedia.
Halaman Utama Katalog
Menampilkan kumpulan produk yang telah dimasukkan ke dalam aplikasi dalam bentuk kartu.
Panduan Menjalankan Aplikasi
1. Unduh repository project atau lakukan clone dari GitHub.
2. Jika project diperoleh dalam bentuk ZIP, ekstrak terlebih dahulu.
3. Buka aplikasi Apache NetBeans IDE.
4. Masuk ke menu File, kemudian pilih Open Project.
5. Cari dan pilih direktori project KatalogProduk.
6. Tunggu sampai NetBeans selesai memuat seluruh library dan dependency Maven.
7. Klik kanan pada project, lalu pilih Clean and Build untuk melakukan proses kompilasi.
8. Setelah proses build berhasil, jalankan aplikasi melalui NetBeans.
